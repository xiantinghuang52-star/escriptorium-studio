# Optional OCR Components / 可选 OCR 组件

The application can download and install these optional tools after the user
presses the corresponding button. Packages are verified against the SHA-256
values below before execution.

用户点击相应按钮后，程序可下载并安装以下可选工具。执行前会验证下载文件的
SHA-256。

## Umi-OCR

- Project / 项目: <https://github.com/hiroi-sora/Umi-OCR>
- Version / 版本: 2.1.5 Rapid
- License / 许可: MIT
- Download / 下载:
  <https://github.com/hiroi-sora/Umi-OCR/releases/download/v2.1.5/Umi-OCR_Rapid_v2.1.5.7z.exe>
- SHA-256:
  `659C55896C32A5E019DC7BDE1713D0E5C73186A2C653BED84C4480FA1795B722`
- Copyright: Copyright (c) 2023 hiroi-sora

## Tesseract OCR

- Project / 项目: <https://github.com/tesseract-ocr/tesseract>
- Version / 版本: 5.5.3 Windows x64
- License / 许可: Apache License 2.0
- Download / 下载:
  <https://github.com/tesseract-ocr/tesseract/releases/download/5.5.3/tesseract-ocr-w64-setup-5.5.3.20260724.exe>
- SHA-256:
  `BEE9E3434BD94FD65387D9BE28CD467A41F61B1275383B55B0F59A1331270AE4`
- Language data / 语言数据:
  <https://github.com/tesseract-ocr/tessdata_fast>

The OCR tools are installed as separate applications and are not embedded in
the main eScriptorium Studio executable. Their upstream licenses continue to
apply.

OCR 工具作为独立程序安装，不嵌入 eScriptorium Studio 主程序，仍受各自上游
许可证约束。
